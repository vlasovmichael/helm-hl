# post-exit-drift — «сколько осталось на столе»

Замер от 29.08.2026. Вопрос оператора: «цена пошла в мою сторону и пошла дальше, а я
просто забрал прибыль — не недобираю ли я систематически?»

Отвечает описательно, **не** предлагает правила выхода: перебор правил уже сделан
в `tools/adoptExitSweep.mjs` (35 правил, ни одно не прошло FDR), а форвард-замер
трейла 0.25R закрыт по стоп-правилу (`tools/adoptShadowTrailStats.mjs`, n=80).

## Как гонять

```sh
# 1. журнал: fills + карта bot-ордеров с Oracle
ssh oracle "docker exec hl-paper-scanner cat data/fills/fills.jsonl" > fills.jsonl
ssh oracle "docker exec hl-paper-scanner node -e \"const D=require('better-sqlite3');\
const db=new D('data/trades.db',{readonly:true});\
process.stdout.write(JSON.stringify(db.prepare('SELECT oid,coin,ts,kind FROM bot_oid_log').all()))\"" > bot_oids.json

python3 build_rt.py        # fills → rts.json (раунд-трипы)
node fetch_candles.mjs 15m # свечи по монетам журнала
node fetch_candles.mjs 1h
python3 drift.py 15m       # горизонты 1/4/24ч, 441 сделка
python3 drift.py 1h        # горизонты 4/24/72ч, все 757
```

## Что меряется

Для каждого раунд-трипа — ход цены **в направлении закрытой позиции** за H часов
ПОСЛЕ выхода. `drift > 0` = терпение добавило бы, `drift < 0` = выход спас.

## Грабли, из-за которых число можно прочитать неверно

- **Без бейзлайна число бессмысленно.** «После выхода цена шла дальше» покажет и
  случайный момент, если монета в этот период просто ехала. Поэтому на каждую
  сделку берутся 20 случайных моментов по ТОЙ ЖЕ монете/стороне/горизонту, и
  в вывод идёт разница. Ноль = мой выход не отличается от случайного.
- **CI кластерный по дням.** Наивный бутстрап по сделкам врал в 11× на MTF-замере
  (см. память `mtf_alignment_backtest_2026_08_24`): сделки одного дня
  коррелированы через общий ход рынка. Ресэмплятся ДНИ целиком.
- **Глубина свечей — лимит 5000 баров НА ИНТЕРВАЛ.** 15m ⇒ только 52 дня назад,
  поэтому на 15m попадает 441 сделка из 757. Полная выборка — только на 1h,
  и там минимальный горизонт 4ч.
- Раунд-трип закрывается по обнулению позиции; долив внутри позиции идёт в
  средневзвешенный вход, а не в новую сделку.

## Результат 29.08.2026 (n=757, 12.06–28.08)

Доля «цена пошла дальше в мою сторону» = **50%** на 1/4/24/72ч, во всех срезах
(плюсовые, минусовые, ручной выход, выход бота, лонги, шорты). Превышение над
случайным моментом +0.1…+0.3пп, ДИ везде накрывает ноль. Медианы «лучшее в окне»
и «худшее в окне» симметричны (+3.2% / −3.1% за 4ч).

Вывод: **систематического недобора нет**, момент выхода неотличим от случайного.
Терпеть дольше = равный шанс добрать и отдать. Ощущение «недобрал» — это память
о победителях, которые пошли дальше, без учёта развернувшихся.
