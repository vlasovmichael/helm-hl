# Мутационные тесты денежных модулей

Команда воспроизведения одного замера:

```bash
npm run mutation -- src/modules/executor/math.js
```

Stryker запускает изолированный набор `node:test` для выбранного модуля. Отчёт
JSON остаётся локальным в `reports/mutation/`.

| Модуль | До: балл / killed / survived / no coverage | После: балл / killed / survived / no coverage | Время |
| --- | --- | --- | --- |
| `executor/math.js` | 28.29% / 43 / 18 / 91 | 90.79% / 138 / 14 / 0 | 18 с |
| `executor/fill-parser.js` | не измерялся | 34.21% / 26 / 50 / 0 | 11 с |

## Выжившие мутанты

### `executor/math.js`

Остались 14 мутантов на пограничных значениях `formatHlPrice`, минимального
размера и вычисления комиссии. Они не эквивалентны; для достижения 100% нужны
дополнительные отдельные сценарии границ.

universe и runtime-blacklist. Для них нужны изолированные фейки `core/universe`
и `executor/state`; их в текущем срезе нет.
