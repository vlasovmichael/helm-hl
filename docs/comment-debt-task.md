# Задача: погасить долг комментариев

Ветка `codex/comment-debt`. Без push. Правила комментариев — CLAUDE.md проекта и
`~/.claude/CLAUDE.md` (разделы «Комментарии»). Сторож: `node scripts/checkComments.mjs`,
долг пофайлово в `scripts/comment-debt.json` (91 файл, 166 нарушений).

- По одному-трём файлам на коммит: переписать нарушающие комментарии по правилам,
  затем `node scripts/checkComments.mjs --update`, долг файла должен уменьшиться до 0.
- Комментарий не удалять, если он объясняет неочевидный код или запрет — переписать
  коротко: «не X: ломается на Y». Удалять только историю, даты, пересказ багов.
- Код не менять, только комментарии. `npm run verify` зелёный на каждом коммите.
- `tools/*.mjs` — методологические шапки не трогать (исключение из правил).
- Готово, когда `scripts/comment-debt.json` пуст. Отчёт `docs/comment-debt-report.md`:
  сколько было/стало, примеры 10 переписанных комментариев «было → стало».
