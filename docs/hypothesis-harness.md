# Харнесс гипотез

`tools/harness.mjs`. Построен 2026-08-07. Реестр: `data/hypotheses/registry.json`
(в git — это протокол исследования, он обязан быть в истории).

## Зачем не просто «прогнать гипотезу»

При α=0.05 каждые 20 прогонов дают одно ложное срабатывание. Оно будет
красивым, и на него уйдут недели — ровно как ушли на няньку. Конвейер устроен
так, чтобы забыть о защите было нельзя.

## Пять правил, встроенных в код

1. **Предзаявление обязательно.** `run()` требует id из реестра; незарегистрированную
   гипотезу прогнать нельзя. Повторная регистрация того же id запрещена —
   иначе формулировку можно было бы подкрутить после первого взгляда на данные.
2. **Реестр append-only и хранит ВСЕ прогоны**, включая пустые и неудачные. Без
   полного счёта поправку не посчитать, а «помню, гоняли штук пять» — не счёт.
3. **Бейзлайн обязателен** — результат без него в реестр не пишется.
4. **Статус «подтверждено» недостижим на одном режиме рынка.** Правило выведено
   07.08.2026 из няньки: 11 259 наблюдений на одном режиме не спасли.
5. **FDR (Benjamini-Hochberg)** считается по всему реестру, а не по последнему прогону.

## Лестница статусов

| статус | когда |
|---|---|
| не прогонялась | зарегистрирована, данных нет |
| ПРЕДВАРИТЕЛЬНО | сработала, но режим рынка один — **это не результат** |
| ОТВЕРГНУТА | не сработала нигде |
| ОТВЕРГНУТА (один режим = бета) | сработала на одном режиме, на другом нет |
| ОТВЕРГНУТА (знак инвертируется) | сработала на обоих, но с разным знаком — случай няньки |
| ВЫЖИЛА на двух режимах | кандидат на holdout |

Обратите внимание: «выжила» — это ещё не «работает». Это право быть проверенной
на holdout.

## Holdout

Данные OI покрывают 12.07–07.08.2026, и весь период — боковик (BTC 62.8k–66.5k,
все 8-дневные отрезки между −2.1% и +2.3%). Второго режима внутри данных нет.

**Поэтому holdout — это будущее.** Подтверждение возможно только когда рынок
сменит режим и коллектор наберёт данные. Такой holdout невозможно подсмотреть и
невозможно подогнать: его физически ещё не существует. Редкая методологическая
удача — обычно за такую чистоту приходится бороться дисциплиной.

## Известные слабости (честно)

- **Скрытые степени свободы в параметрах.** Пороги гипотез (3%, 0.5%, 4 часа)
  выбраны рукой. Формально тестов четыре, фактически пространство выбора шире, и
  FDR по четырём тестам это недооценивает. Лечится только тем, что пороги
  зафиксированы ДО прогона и меняться не будут.
- **Cooldown вместо честной независимости.** События одной монеты разведены на
  длину сделки, но события разных монет в один час коррелированы через рынок.
  Эффективное n меньше номинального.
- **15m свечи** — правила и удержания короче бара измеряются грубо.

## Первый прогон: 4 гипотезы на OI/funding (07.08.2026)

Окно 12.07–07.08, боковик. Три гипотезы мертвы, одна — слабый кандидат.

| гипотеза | n | реально | случайно | p (time) | итог |
|---|---|---|---|---|---|
| `oi-up-px-flat` | 368 | +0.084% | −0.188% | **0.0199** | предварительно |
| `funding-extreme` | 349 | +0.190% | −0.174% | 0.0697 | отвергнута |
| `oi-drop-px-drop` | 102 | −0.213% | −0.114% | 0.8408 | отвергнута |
| `oi-px-divergence` | 472 | −0.140% | −0.159% | 0.8905 | отвергнута |

**Выживший проходит только 1 из 3 нулевых моделей:** time p=0.0199, но coin
p=0.164 и side p=0.124. Настоящий сигнал должен зависеть и от момента, и от
монеты, и от стороны — здесь значим лишь момент. Это слабейший вид
свидетельства, и с учётом 3 моделей × 4 гипотезы = 12 тестов реальная поправка
жёстче, чем посчитанный FDR по восьми.

**Честный статус: ничего не подтверждено.** `oi-up-px-flat` — не находка, а
единственный кандидат, доживший до проверки на втором режиме рынка.

## Использование

```js
import { preregister, run, report, status } from "./harness.mjs";

preregister({ id, description, condition, side, holdMin, rationale });
run(id, events, { window: "...", regime: "рост|боковик|падение" });
console.log(report());
```
