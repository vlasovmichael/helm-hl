# Цвета витрины через токены кита

## Результат

Сырые цвета в области проверки устранены: `node scripts/checkRawColors.mjs`
показывает долг `0`. Сторож добавлен в `npm run guards`; `--update` записывает
только уменьшившуюся планку. Исключены только `src/dev/` и файл определений
локальных токенов; последний теперь тоже ссылается на палитру `--color-*` кита.

Механическая замена выполнена `scripts/migrateRawColors.mjs`; скрипт остаётся
в истории, повторный запуск идемпотентен.

## Сырой цвет → токен

| Группа исходных цветов | Замена |
| --- | --- |
| зелёные PnL и положительные состояния | `--gain`, `--gain-wash`, `--gain-line` |
| красные ошибки и отрицательные состояния | `--loss`, `--loss-wash`, `--loss-line` |
| янтарные предупреждения и EMA | `--caution`, `--attn`, `--plot-ema` |
| синие и фиолетовые акценты | `--accent`, `--accent-2`, `--wash` |
| белый текст на цветной заливке | `--accent-ink` |
| серые поверхности, текст и линии | `--panel*`, `--ink*`, `--rule*`, `--plot-grid` |
| прозрачные варианты | `color-mix()` от соответствующего токена |

Созданные локальные токены не добавлялись: существующие `--pnl-*`, брендовые,
tier и skeleton-токены сохранены, но теперь определяются через палитру кита.

## Визуальная сеть

Стенд строит витрину (`npm run build:dash`) и отдаёт только `dist`, с
детерминированными API-ответами и WS-фикстурой. Для каждого кадра он пишет
HTTP/WS-журнал, слушает `console`, `pageerror` и `requestfailed`, сохраняет
Playwright trace и валит кадр при Vite overlay, неправильном `--ground`,
отсутствии класса именно этой страницы или менее 50 цветов. `page.clock`
ставится после `DOMContentLoaded`; rAF учитывается и заморожен в фикстуре.

Причина зависания была в самом стенде: он открывал `/index.html`, тогда как
History-router регистрирует `/`. Роутер выполнял `location.href =
"/index.html"`, отчего документ бесконечно перезагружался. Trace подтвердил
повторяющиеся `index.html → assets → /api/notifications`; внешних зависших WS
и бесконечного rAF нет. Теперь router-страницы открываются по production URL
(`/`, `/oi`, `/journal` и т. д.); для статической подачи им сопоставляются их
HTML-входы. Chromium в sandbox также не запускался (`MachPortRendezvous:
Permission denied`); успешный прогон выполнялся вне него локально.

Эталоны «до» сняты из временного worktree `a3ac380`; «после» — из `c979dfa`.
Ни один зелёный результат не взят из старой невалидной сети.
