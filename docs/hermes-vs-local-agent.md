# Замер: Hermes Agent против local-agent.mjs

Цель — решить судьбу 519 строк собственного агентного каркаса (реестр
инструментов, цикл вызовов, защита от зацикливания). Если готовый Hermes на том
же железе и той же модели справляется не хуже, свой каркас идёт под нож, а
`doc-ocr` подключается к Hermes скиллом.

Критерий записан **до** запуска, чтобы результат нельзя было подогнать.

## Железо (потолок, который не сдвинуть)

- MacBook Pro 2018, Intel Core i7-8750H, 16 ГБ ОЗУ
- ollama работает **на CPU**, без GPU-ускорения (`ollama ps` → `100% CPU`)

Замеренный расход памяти при большом окне:

| Модель | Окно | В памяти |
|---|---|---|
| qwen2.5-coder:7b | 64k | 6.9 ГБ |
| qwen3:8b | 32k | 10 ГБ |
| qwen3:8b | 64k | ~15 ГБ — **не влезает** |

Hermes требует минимум **64k** контекста для работы с инструментами
(документация: «Hermes requires at least 64,000 tokens for agent use with tools»).
Отсюда следствие, важное для честности замера: на этой машине Hermes может
работать только с `qwen2.5-coder:7b` — то есть с той моделью, которая в наших
тестах путала имена. `qwen3:8b`, отвечавшая верно, в 64k здесь не влезает.

## Задача

Файл: `~/Downloads/ПМЖ/SKM_C30826072315052.pdf` — присяжный перевод акта
о рождении 1988 года с русского на польский, скан с МФУ, 1 страница.

Вопрос: `что это за документ? одной строкой + ФИО и номер как в бумаге`

Правда по документу (сверено глазами по вырезке из скана):

- переводчик: **Danuta Olszewska**, repertorium **1613/2026**
- ФИО: **Vlasov Mykhailo Iurevich**, `[syn Iuriia]`
- место рождения: **m. Charków**
- номер бланка: **IV-VL Nr 419702**, запись № 826 от 1 сентября 1988

## Что считаем успехом

1. Имена и номера — как в бумаге, без выдумок.
2. Номер `419702` присутствует и не искажён.
3. Нет смешения алфавитов внутри слова (`Чаркowie` — брак).
4. Ответ получен за разумное время на CPU (ориентир: наш цикл — до 2 минут).

## Базовая линия: local-agent.mjs (замерено 12.08.2026)

| Модель | Ответ | Ошибки |
|---|---|---|
| qwen2.5-coder:7b | «свидетельство о рождении Mykhaila Iurevicha Vlasova (сына Турии), родившегося 28 июля 1988 года в Чаркове» | «сына Турии» (OCR быстрым набором + не поправлено), «Чаркове» |
| qwen2.5-coder:7b (до правил) | «перевод… выданного в Чаркowie… переводчиком Данилой Ольшевской» | смешение алфавитов, выдуманное имя |
| qwen3:8b (после правил + tessdata_best) | «копия акта о рождении Михаила Юрьевича Власова, выданного в Харькове 1 сентября 1988 года. ФИО: Власов Михаил Юрьевич. Номер: 419702» | нет |

Итог базовой линии: свой каркас проходит критерий **только** на `qwen3:8b`.

## Результат: Hermes на локальной модели на этом железе не запускается

Установлен 12.08.2026 из исходников (`~/.hermes/hermes-agent`, venv на Python
3.11.15, `hermes` в `~/.local/bin`), настроен на второй сервер ollama
(`127.0.0.1:11435`, поднят с `OLLAMA_CONTEXT_LENGTH=64000`, чтобы не трогать
менюбар-приложение). `hermes doctor --fix` прошёл, инструмент `terminal` включён.

Первый же запрос отклонён самим Hermes:

> Ollama loaded `qwen2.5-coder:7b` with only 32,768 tokens of runtime context,
> but Hermes needs at least 64,000 tokens for reliable tool use.

Порог — константа `MINIMUM_CONTEXT_LENGTH = 64_000` в `agent/model_metadata.py`,
без переменной окружения, с комментарием «схемы инструментов и системный промпт
занимают большой фиксированный префикс». Обходить её патчем исходников
бессмысленно: замерять пришлось бы искалеченный Hermes, а не Hermes.

Обе локальные модели упираются в разное:

| Модель | Ограничение |
|---|---|
| qwen2.5-coder:7b | нативное окно **32k** — 64k не умеет физически |
| qwen3:8b | 64k требует ~15 ГБ (замер: 10 ГБ при 32k) — не влезает в 16 ГБ |

Но даже при достаточной памяти дело решает не она, а скорость CPU. Замер на
qwen2.5-coder:7b, i7-8750H, без GPU:

| Что | Скорость |
|---|---|
| обработка промпта (prefill) | **26.3 токен/с** (1119 токенов за 42.5 с) |
| генерация ответа | ~6.4 токен/с |

Отсюда прямые следствия для агента с большим системным промптом:

- префикс ~15k токенов (системный промпт + схемы 40 инструментов) —
  **9.5 минуты на каждом шаге**, а не только на первом;
- заполненное окно 64k — **40 минут** только на чтение контекста;
- контрольная проверка: префикс на ~10 000 токенов действительно **не
  обработался за 10 минут**.

Вывод: свои 519 строк каркаса тут не при чём — упор в железо 2018 года.
Локальный агент на этой машине возможен только с маленьким окном и без
40 инструментов, то есть примерно таким, как `local-agent.mjs`.
