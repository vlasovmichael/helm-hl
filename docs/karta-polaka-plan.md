# Карта Поляка → ПМЖ → гражданство: план для мамы и меня

> Практический маршрут к польскому (= ЕС) паспорту через **польское происхождение**.
> Основание: мамин отец **Вацлав — «поляк»** по свидетельству (документально подтверждено).
> Путь «гражданство по крови» (potwierdzenie) — скорее всего закрыт (предки уехали из
> Польши в ~1914, до создания государства 1918, гражданства Второй Речи Посполитой не имели).
> Поэтому идём через **Карту Поляка** — это сильный путь, оба квалифицируются.

- Основание: то же — хотя бы один родитель/дед/двое прадедов польской национальности + декларация польской национальности. Мама — по отцу (Вацлав), я — по деду. Оба квалифицируются.
