# Hyperliquid Agent Wallet — Пошаговый гайд

## Что такое Agent Wallet?

Agent Wallet (API Wallet) — это **отдельный приватный ключ**, авторизованный
твоим основным кошельком для торговых операций.

**Может:** выставлять/отменять ордера, менять leverage, управлять маржой.
**НЕ может:** выводить средства, делать переводы, управлять vault'ами.

Это значит: даже если ключ утечёт — деньги не уведут, только наторгуют.

---

## Шаг 1: Открой страницу API

Зайди на https://app.hyperliquid.xyz/API

Убедись, что ты подключен тем же кошельком, на котором лежат деньги
(тот же `PUBLIC_WALLET_ADDRESS` из нашего `.env`).

---

## Шаг 2: Создай нового Agent

На странице ты увидишь раздел **"API Wallets"** (или "Agent Wallets").

1. Нажми **"Generate API Private Key"** (или "Create New Agent")
2. Подпиши транзакцию `approveAgent` в MetaMask/Rabby — это
   регистрирует новый ключ как авторизованного агента
3. Сайт покажет:
   - **Agent Wallet Address** — `0xABC...` (публичный адрес)
   - **Agent Private Key** — `0xDEF...` (приватный ключ)

---

## Шаг 3: ОБЯЗАТЕЛЬНО сохрани ключи

> **ВНИМАНИЕ:** Приватный ключ показывается **ОДИН РАЗ**.
> Если закроешь страницу — восстановить его невозможно.
> Придётся создавать нового агента.

Скопируй и сохрани:

```
HL_AGENT_PRIVATE_KEY=0xDEF...   # Приватный ключ агента
HL_AGENT_ADDRESS=0xABC...       # Адрес агента (для логов/дебага)
```

---

## Шаг 4: Обнови .env нашего бота

```env
# ── Режим торговли ──────────────────────────────
TRADING_MODE=PRODUCTION

# ── Кошелёк ─────────────────────────────────────
PUBLIC_WALLET_ADDRESS=0xТвойОсновнойАдрес

# ── Agent (API Wallet) ──────────────────────────
HL_AGENT_PRIVATE_KEY=0xКлючАгента
```

Поле `HL_PRIVATE_KEY` (основной ключ) **НЕ НУЖНО** для торговли через агента.
Мы используем его только как fallback проверку при старте в PRODUCTION.

---

## Важные ограничения

| Параметр | Значение |
|----------|----------|
| Unnamed agents | 1 на аккаунт (создание нового деактивирует старого) |
| Named agents | до 3 на основной аккаунт, +2 на каждый субаккаунт |
| Nonce | Привязан к адресу агента, окно: (T - 2 дня, T + 1 день) |
| Срок жизни | Бессрочный (если не задать expiry при создании) |

---

## Проверка

После создания агента можно проверить его через API:

```bash
curl -s https://api.hyperliquid.xyz/info \
  -H "Content-Type: application/json" \
  -d '{"type":"clearinghouseState","user":"0xТвойОсновнойАдрес"}' \
  | jq .
```

Если возвращает данные — аккаунт активен и агент может торговать от его имени.

---

## Безопасность

1. **Никогда** не коммить `.env` файл с ключами в git
2. На сервере храни ключи в Docker secrets или переменных окружения
3. Agent wallet **не держит средства** — он только подписывает ордера
4. Если подозреваешь утечку — зайди на https://app.hyperliquid.xyz/API и
   создай нового агента (старый автоматически деактивируется)
