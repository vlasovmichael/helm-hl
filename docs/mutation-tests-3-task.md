# Задача 3: мутации — остальной код бота

Те же правила, инфраструктура и отчёт (раздел «Этап 3»). Ветка та же.

Все `src/core/*.js` и `src/modules/*.js` (без `dashboard/`, `taxCollector/`), у которых
ещё нет строки в отчёте. Порядок: сначала то, что трогает деньги или ордера
(`exchange.js`, `sync.js`, `execCosts.js`, `funding.js`, `carry.js`, `scout.js`,
`hotMoversSetup.js`, `src/core/*`), затем остальное. Цель ≥ 80% на модуль.

Модуль, который без сети не тестируется осмысленно, — строка в отчёте с причиной,
не натягивать моки ради балла. Продовый код не менять, баги — в «Найденные баги».
Модуль = коммит. Готово, когда у каждого файла из списка есть строка «после» или причина.
